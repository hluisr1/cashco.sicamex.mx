1. Módulos del Sistema

🏢 Módulo de CEDIS (Centros de Distribución)

Gestión de los centros de distribución que almacenan y distribuyen productos a diferentes regiones.

  • Alta, baja y modificación de CEDIS
  • Geolocalización de cada centro
  • Información fiscal y de contacto
  • Asignación de usuarios y clientes por CEDIS

👥 Módulo de Usuarios

Administración de usuarios del sistema con diferentes niveles de acceso y permisos.

  • Tipos de usuario con niveles de autenticación (Auth)
  • Registro de usuarios con información completa
  • Control de estado (Activo/Inactivo)
  • Asignación de usuarios a CEDIS específicos

📦 Módulo de Productos

Catálogo completo de productos comercializados, organizados por marcas y grupos.

  • Gestión de marcas comerciales
  • Clasificación por grupos/categorías
  • Precios y códigos de producto
  • Seguimiento de cargas, ventas e inventario

🏪 Módulo de Clientes

Base de datos de clientes y tiendas con información detallada y geolocalización.

  • Registro de clientes con datos completos
  • Asignación a CEDIS de referencia
  • Coordenadas GPS para rutas
  • Control de estado del cliente

🗺️ Módulo de Rutas y Visitas

Planificación y seguimiento de rutas de reparto y visitas a clientes.

  • Creación de rutas por CEDIS
  • Tipos de ruta (Reparto, Cobranza, etc.)
  • Registro de visitas programadas
  • Seguimiento de estatus de visita

🚚 Módulo de Entregas

Registro detallado de entregas de productos realizadas en cada visita.

  • Detalle de productos entregados
  • Cantidades y totales monetarios
  • Relación con promociones vigentes
  • Inventario inicial y final
  • Identificación del vendedor responsable

↩️ Módulo de Devoluciones

Gestión de devoluciones de productos con causas y proceso de autorización.

  • Catálogo de causas de devolución
  • Registro de devoluciones con validación
  • Proceso de autorización
  • Seguimiento de entrada a almacén
  • Cálculo de montos devueltos

📊 Módulo de Indicadores

Panel de control con métricas e indicadores de gestión del negocio.

  • KPIs de ventas y entregas
  • Métricas de eficiencia por ruta
  • Comparativo vs metas establecidas
  • Indicadores de cobranza

2. Entidades Principales - Diccionario de Datos

📍 CEDIS
Tabla Principal Maestra
Descripción: Representa los Centros de Distribución de la empresa. Cada CEDIS es una ubicación física donde se almacenan productos y desde donde se gestionan las operaciones de reparto a clientes en una región específica.
Campo Tipo de Dato Longitud Nulo Llave Descripción
id INT 11 NO PK Identificador único del CEDIS (Autoincremental)
Nombre VARCHAR 100 NO - Nombre comercial o identificador del CEDIS
Latitud DOUBLE - SI - Coordenada de latitud para geolocalización
Longitud DOUBLE - SI - Coordenada de longitud para geolocalización
nEmpresa VARCHAR 100 SI - Razón social de la empresa propietaria
RFC VARCHAR 20 SI - Registro Federal de Contribuyentes
Telefono VARCHAR 20 SI - Número telefónico de contacto
Domicilio VARCHAR 255 SI - Dirección física completa del CEDIS
👤 TipoUsuario
Catálogo Seguridad
Descripción: Define los diferentes tipos de usuarios que pueden acceder al sistema, cada uno con un nivel de autenticación (Auth) que determina sus permisos y accesos.
Campo Tipo de Dato Nulo Llave Descripción
id INT NO PK Identificador único del tipo de usuario
Nombre VARCHAR(50) NO - Nombre del rol (Admin, Supervisor, Vendedor, etc.)
Auth INT NO - Nivel de autenticación (100=Admin, 75=Supervisor, 50=Vendedor, 40=Almacenista, 25=Consultor)
Descripcion VARCHAR(255) SI - Descripción detallada de permisos y responsabilidades
